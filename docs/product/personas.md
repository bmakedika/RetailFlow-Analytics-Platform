## Data Engineer

### Responsabilités

- Maintenir les pipelines
- Garantir la qualité des données
- Gérer la plateforme analytique

### Objectifs

- Construire un pipeline fiable et résilient aux erreurs
- Assurer la traçabilité des données à chaque étape du pipeline
- Automatiser l'ingestion et les transformations sans intervention manuelle
- Garantir la qualité des données via des tests DBT (not_null, unique, accepted_values)
- Assurer la reproductibilité de l'environnement via Docker
- Maintenir une intégration continue opérationnelle (CI/CD GitHub Actions)
