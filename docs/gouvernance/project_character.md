# Project Charter

## Nom du projet

RetailFlow Analytics Platform

## Contexte

Les données e-commerce sont souvent stockées dans plusieurs systèmes et exploitées essentiellement à des fins opérationnelles

Cette approche limite la capacité des équipes à analyser efficacement :

- les revenus
- les comportements clients
- les performances produits
- les tendances commerciales

RetailFlow vise à transformer ces données en un actif stratégique

## Vision

Transformer les données e-commerce en informations fiables et actionnables afin d'améliorer la prise de décision

## Objectifs métiers

- Suivre l'évolution du chiffre d'affaires
- Mesurer l'activité commerciale
- Identifier les produits performants
- Comprendre le comportement client

## Objectifs techniques

- Automatiser l'ingestion
- Centraliser les données dans BigQuery
- Construire un modèle analytique DBT
- Produire des tableaux de bord

## Critères de succès

- Pipeline automatisé
- KPI fiables
- Dashboard accessible
- Reproductibilité via Docker
